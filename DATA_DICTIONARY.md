# Data dictionary

## dataset_per_clip.csv (real data, 270 rows = one row per video clip)

8 subjects (A–H); subject A was recorded on two separate days, giving 9 sessions
× 30 clips = 270 clips. Each clip is one static shoulder-abduction pose held at a
goniometer-set angle, filmed from one camera azimuth. Per-frame MediaPipe
landmarks were reduced to one representative value per clip (median over frames
with all required landmarks at visibility ≥ 0.5).

| column | meaning |
|---|---|
| `subject_id` | folder index 1–9 (note: 1 and 3 are the same person, subject A, two rounds) |
| `person` | subject identity A–H (8 distinct people) |
| `round` | recording round for that person (A has rounds 1 and 2; others 1) |
| `true_angle` | goniometer-set shoulder-abduction angle, degrees (0,30,60,90,120,150) — the reference |
| `azimuth` | camera azimuth relative to frontal, degrees (0,30,45,60,90) |
| `rep` | repetition index within a session |
| `clip` | source video filename (camera-assigned; no personal information) |
| `baseline_nose` | estimated angle, nose-referenced 2D method (degrees) |
| `2d_trunk` | estimated angle, trunk-referenced raw-2D method (degrees) |
| `bonelength` | estimated angle, proposed training-free bone-length correction (degrees) |
| `3d_world` | estimated angle from MediaPipe 3D world landmarks (degrees) |
| `feat_armlen` | projected upper-arm length, pixels (observable feature) |
| `feat_trunklen` | projected trunk length, pixels |
| `feat_ratio` | feat_armlen / feat_trunklen |
| `studied_side` | arm analyzed, "L" or "R" (auto-detected) |
| `vis_shoulder` | mean MediaPipe visibility of the shoulder landmark (0–1) |
| `vis_elbow` | mean MediaPipe visibility of the elbow landmark (0–1) |
| `n_det` | number of frames in which the pose was detected |

## synthetic_dataset.csv (synthetic projection model, 2100 rows)

Same estimator columns (`baseline_nose`, `2d_trunk`, `bonelength`, `3d_world`,
`feat_*`) plus `true_angle`, `azimuth`, `rep`, generated by the projection model
(no video). Used for the geometric proof and the data-efficiency analysis.
